# ONE 40项技能首版

这批功能由 ONE 独立编写。公开项目只用于了解需求切入点，没有复制他人的提示词、代码或付费技能。

首次部署会添加缺失的功能，并在有可用模型时先对管理员开放。已有配置、人工修改和上架范围不会被覆盖。其他账号从后台单项选择接收人发布。

使用入口：我的功能／官方精选。配置入口：后台 → 官方智能体 → ONE 内置功能；每项分别修改提示词、选项和按钮，保存后认定新版本，再发布。

## 运行与维护

每个目录有 SKILL.md、config.json 和参考示例。共享金额脚本在 shared/scripts/finance.mjs；报价与利润示例在 shared/examples。表格脚本在 server/skillTables.ts，通过受限工具运行，不执行用户上传的任意脚本。

`node scripts/build-one-skills.mjs` 重建40项配置；提示词与选项的维护源是该脚本。`node scripts/package-one-skills.mjs` 在 output/one-skills 保存每项 ZIP 和合集。后台支持 .md，以及包含一个 SKILL.md、可选 config.json 和 Markdown 参考资料的 ZIP。

## 首版边界

- 计算依据输入口径，不预测获客量与业务效果。金额使用十进制半入取整，报价区分含税、运费与币种。
- 表格支持 CSV/XLSX：最多5个选中附件，单文件2MB、单工作表、2000条数据、40列；合并结果也最多2000条，需一致的列名与顺序，不支持任意关联。重复键由用户确认，空键记录保留。
- 图片依赖已配置图片模型；首版沿用方形图片输出。职业形象照要求本人参考照片，身份与文字需人工核对。
- 宠物医院活动包当前生成海报文案和构图说明；图片制作使用文章与活动封面功能。
- 竞品功能整理已提供的材料或知识检索结果。仅给网址不能声称已访问网页，不具备独立网页抓取工具。
- 文稿支持 Markdown 和 HTML 下载，没有自动发送、自动发布或 Word 编辑流程。
- 陪练支持“继续练习或修改结果”；每一轮有独立费用与任务回执，延续最近一轮材料，不假装拥有完整无限历史。
- 宠物医院功能聚焦经营与服务。医疗内容引用医院批准资料，由兽医审核，不给个体诊疗或用药结论。

## 验证范围

已验证：24项配置和默认选项、三种金额运算、明确键的去重、日历异常、完整表格拼接、私有成果保存、跨用户与跨空间拒绝、任务幂等与续接、图片模型调用与撤权后的保存阻断。浏览器使用合成模型验证控件、完成回执和下载；不能据此认定24个真实模型输出质量已验收。
