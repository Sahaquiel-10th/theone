# ONE 产品基线

> 状态：快速上线 MVP，2026-08-30

## 产品定义

ONE 是一个以硬件身份入口启动的多租户个人 AI 工作平台。用户只需登录一次 ONE、授权一次自己的知识平台，之后即可在 ONE 中让 AI 直接使用这些知识。

得到大脑只是首个 Knowledge Connector。后续可以连接 Notion、印象笔记和 ONE 自有知识库，但业务层不绑定任何单一平台。

## MVP 用户承诺

> 插入 ONE Key，双击打开 ONE；首次认领 Key 并确认知识平台授权，此后直接向 AI 提问，ONE 自动使用该用户已经授权的个人知识。

## ONE Key 产品结论

- ONE Key 首版使用普通 U 盘，不加入 NFC；NFC 名片只作为“批量生成唯一认领码、首次认领、不可重复绑定”的流程参考。
- 批量灌装时，每枚 Key 写入相同 Launcher、唯一序列号和一次性认领码，状态为“未激活”，不提前绑定用户。
- 用户首次双击后通过手机号验证码或微信认领；正式设备密钥在首次激活时生成，私钥留在 Key，公钥上传服务端，一次性认领码随即作废。
- 一个账号允许绑定多枚 ONE Key。每枚 Key 有不可变序列号、外壳短编号、用户自定义名称、状态和最近使用时间。
- 挂失后设备永久作废并自动进入归档，不再出现在正常设备列表；服务端保留最小安全记录，不恢复、不复用序列号。
- 普通 U 盘凭证可被复制，首版只作为产品原型安全边界，不宣传为安全芯片。

## Key 使用模式

- **严格模式**：页面可以保留已经显示的内容，但每次读取私人数据、发送消息、召回知识或修改后台前，都必须由 Launcher 重新读取 U 盘私钥并完成一次性请求签名；Key 不在场时该请求直接拒绝，不使用业务心跳，也不主动遮盖当前页面。
- **受信任设备模式**：用户用 ONE Key 授权自己的电脑后，普通功能可以长期登录；连接/断开知识平台、数据导出或删除、增删 Key、增删受信任设备、账号恢复与其他敏感操作仍要求 Key 在场。
- 首版先完成严格模式和真实 U 盘闭环，再增加受信任设备模式。
- 普通 U 盘可以被复制，但副本只能克隆同一个设备身份，不能生成新用户、余额或独立 Key。多个副本共享账号和电力；同一设备 ID 只允许一个 Launcher 在线，并记录并发连接异常。真正的私钥不可导出能力留给后续安全芯片版本。

## MVP 前提

- 用户已经注册得到大脑并开通会员；
- 无账号用户暂由 ONE 运营人员逐笔协助注册和开通；
- 用户第一次仍需在得到官方页面完成登录/短信验证/授权；
- ONE 不绕过第三方授权，也不共享多个客户的得到账号；
- AI 中转 API 由产品方后续提供，开发阶段沿用现有 Model Gateway。
- 普通用户无需理解模型或 Token；默认直接工作，需要时才在设置中切换模型、查看电力和充值。

## MVP 旅程

1. 运营批量生成未激活认领码并灌装 ONE Key，不提前绑定用户。
2. 用户插入 U 盘，双击对应系统的 ONE Launcher。
3. 首次使用通过手机号验证码或微信认领，创建/匹配用户和 Workspace，并绑定该 Key。
4. Launcher 完成设备 challenge，浏览器兑换 HttpOnly Session 并进入 ONE。
5. 首次使用检测到没有知识连接，提示连接得到大脑。
6. 用户在得到官方页面完成一次 OAuth 授权；用户不进入开发者后台、不复制 API Key。
7. ONE 按 Workspace 加密保存授权凭据。
8. 用户在 ONE 提问；服务端实时调用得到全局语义搜索。
9. 召回结果作为不可信参考上下文注入 AI，并展示来源。
10. 后续插 Key、双击即可进入；得到授权仅在过期或撤销时需要重新确认。

## MVP 必须有

- Workspace 数据隔离；
- ONE Key Launcher、设备凭证、challenge、一次性登录码和浏览器 Session；
- 未激活认领码、首次用户绑定、一个账号多 Key、设备命名、挂失归档和在线许可；
- 得到大脑一键授权、连接状态、重新授权和断开；
- 得到全局语义召回；
- 召回结果注入 AI 上下文并展示来源；
- 模型网关与后续 AI 中转 API 的适配边界；
- 最小运营开户、Key 初始化、挂失和错误诊断；
- 超管模型上架、进价/售价、电力赠送、账单与非内容审计日志；
- 普通用户独立电力账户、充值入口与模型偏好；
- Windows x64、macOS Apple Silicon 首发路径；
- 真实账号端到端验证、跨租户测试和基础监控。

## MVP 不做

- 在 ONE 保存得到/Notion/印象笔记知识正文；
- ONE 自有知识库、定时多渠道同步和本地向量库；
- 状态化 Memory、观点演化、动态知识 View；
- Notion、印象笔记等第二个 Connector；
- 完整笔记编辑器、文件树和知识整理系统；
- 自动支付到账（首版仅保留充值订单与人工入账）、智能体市场和复杂财务报表；
- 硬件安全芯片级不可复制承诺。

## 后续产品方向

V2 再建设多渠道内容同步和 ONE 自有知识副本；V3 再引入“文档是视图、知识是活记忆”的 Source/Memory/View 体系。相关理念保留为长期方向，但不得阻塞首版上线。

## 成功标准

- 新用户在人工预开通得到会员后，可以独立完成首次授权；
- 插 Key 到打开 ONE 的主流程可用；
- 严格模式拔出 Key 后在约定租约内锁定，挂失后不能建立新许可；
- 已连接用户的普通问题可以命中其得到笔记并交给 AI；
- Workspace A 无法使用 Workspace B 的 Key、连接、召回结果或会话；
- 断开/过期后立即停止第三方召回；
- Provider 凭据不进入浏览器、URL、日志或 AI 上下文；
- 一次完整演示不需要打开得到大脑查看或复制笔记。
