# 分身工作台整理与验收 · 2026-10-26

## 目标与范围

以老师配置、试聊、修改、分享的实际顺序整理现有模块。保持 ONE 玻璃材质和分裂工作面板，不改生产价格、用户余额、公开权限或既有分享。

## 本轮改动

1. 左侧独立「功能」「分身」入口；普通与新版工作台均隔离目录。
2. 售前咨询／知识服务分别展示服务目标、资料示例、问题示例、工具建议与收费／留资指引。切换不覆盖作者已填内容、不自动改变权限或价格；模型沿用相应服务目标。
3. 配置分为身份与用途、资料与方法、回答方式、访客开场、收费与访问、客户信息。文档导入置于资料区首要操作，明确目前支持 TXT／Markdown，追加而非覆盖。
4. 功能主界面仅显示已选项和最多三项建议。完整目录在可搜索、分页弹窗中，保留最多四项公开交付功能边界。
5. 「收费方案」「收集客户信息」说明谁填写、谁收款、用途及限制，不暗示自动代收款、续费、分账或提现。
6. 旁边分裂独立访客预览与调试。外观预览免费；实际回答须明确确认使用作者电力。私测只问答与所选知识检索，不执行功能、上传附件、提交联系信息、公开分享或向访客收费。
7. 未分享及已分享分身均有明确编辑入口。关闭过的分享不自动复活，可复制为新的未分享分身；复制移除旧方案身份，不复制订单、资格、客户信息、历史或分享链接。
8. 分身列表拥有唯一主滚动面，卡片不再截获滚轮。编辑与调试各自为整面板滚动，无小卡片内滚动。

## 私测恢复与隔离

- 操作编号、原配置、问题及有界历史构成不可变提交。同账号／空间／编号同内容回取持久原回执，不重复调用或扣费。
- 配置变更保留旧回答并明确标记，新开试聊才使用新配置；切换账号／空间清空本地会话。
- 同次登录切换分身或关闭编辑器，父层缓存每位分身的未确认编号，重开可核对；刷新整个网页不自动重跑。
- 试聊结果仅保存在私有操作回执，不进入访客接口、管理日志正文或一般聊天历史。
- 私测不校验尚未写完的工具调用条件（因为不会执行工具）；正式保存／发布仍完整校验。
