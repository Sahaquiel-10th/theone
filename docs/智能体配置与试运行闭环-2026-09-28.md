# 智能体配置与试运行闭环

本轮目标不是另做接入管理页面，而是从一个智能体出发完成：用途 → 模型/提示词 → 可选工具及调用条件 → 保存 → 输入任务 → 模型按需调用 → 结果、调用轨迹和本次费用。

个人分享分身的问答与附件边界不变；本轮为 Key 在场的超管本人调试，不上架公共目录、不开放创作者上传。

工具是多选组合，不再与“问答模板”互斥。先内置已验证的合成资料查询、库存查询；允许添加支持子集的 OpenAPI JSON 定义，目标地址必须经过服务端精确允许列表审核。MCP、需要凭证的接口、写入接口尚未支持，不提供可选却无法配置的假入口。不会为了让任意地址能用而关闭网络隔离。

模型试运行走既有计费预留/结算，显示费用确认及总电力上限。使用既有幂等记录防止重试重复扣费；结果和工具轨迹只存于发起管理员本人的空间，不放到全局功能配置或运营审计里。新试运行从已保存草稿的固定 revision 开始，变更/停用/拔 Key 后不得继续工具或模型调用。

试运行是独立任务，不会自动发布。草稿、认定版本、线上目录是不同状态。已有纯说明配置可继续编辑，只有配置模型后才能试运行。

验证：配置版本兼容、工具参数与地址约束、真实路由角色与空间隔离、可复用结果/禁止重放、运行中撤权、预算预留、多步调用轨迹、浏览器表单及窄屏布局。不得为验证自动扣生产账号电力。

## 后台使用方法

在管理中的官方智能体列表新增或打开配置，填写用途、执行要求和边界，选择已启用的对话模型；勾选多个工具，并分别填写什么时候调用、参数怎么填。保存草稿之后展开“试运行智能体”，输入任务和电力上限，确认实际用量计费。回答下面可展开工具参数、返回内容和各次模型电力。

首次可选“测试资料查询”和“测试库存查询”，输入“会议室能预约多久？白板笔还有多少？”；数据为虚构园区资料，不能作为真实业务依据。模型是否正确选择工具须用实际模型验收，自动测试中的模型响应不代表模型质量验收。

外部 OpenAPI 接入：维护者先审核精确 HTTPS 接口地址，加入服务端 `ONE_FEATURE_HTTP_ENDPOINTS`（逗号分隔），再重启 ONE。后台展开“添加 HTTP / OpenAPI 工具”，粘贴定义并填写 operationId，然后添加到该智能体、编辑调用条件并保存。目前仅支持 OpenAPI 3.1 子集：GET、query 标量参数、200 JSON 对象及标量返回字段；不支持鉴权、引用、嵌套结构和任意地址。地址审核不依赖浏览器声明。后续凭证管理、MCP 及写入适配另行扩展。

本地验证结果：319 项测试，318 通过、1 项跳过；TypeScript 与生产构建通过。隔离浏览器验证了多工具勾选、保存、确认费用、结果呈现以及 390px 窄屏无横向溢出。未消耗生产账号电力，真实模型效果仍需管理员在上述入口验收。
