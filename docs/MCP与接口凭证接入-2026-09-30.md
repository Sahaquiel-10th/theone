# MCP 与接口凭证接入

本批接续官方精选灰度运行：外部能力是智能体的一部分，不新增开放工具市场。

## 范围

- 支持已审核 HTTPS 精确地址的只读 MCP：初始化、发现工具、选择并人工确认只读、固定定义、运行前检查漂移，再调用。参数先支持扁平标量对象，结果支持文本/结构化 JSON；不读取返回的资源地址，不支持本机 stdio、脚本、OAuth、写入及采样等反向请求。
- Streamable HTTP 采用有界单次请求模式，处理 JSON/SSE 响应；不支持旧 SSE transport、断线续流、自动重试或服务端发起的交互。协议失败明确报错，不伪装成功。
- 现有 OpenAPI GET 工具可独立配置鉴权方式：无、Bearer、X-API-Key。鉴权在工具配置中声明，不把密钥写进 OpenAPI 或提示词。OpenAPI security 声明仍不是本解析子集的一部分。
- 凭证归使用者自己的 workspace/user/精确 endpoint/auth，使用既有 AES-GCM 加密且绑定这些字段；普通接口只返回配置状态。存储于本人 user 的独立扩展字段（每条仍有 workspaceId/userId），无需迁移。管理员试运行用自己的凭证，普通用户使用自己的；共享凭证不支持。
- 替换或撤销凭证、移除允许地址、工具定义漂移、下架、拔 Key 都会阻止后续调用。凭证值不放进模型、URL、日志、响应或全局定义。
- 保留私网/DNS 重绑定防护、固定 IP TLS、响应与超时上限、禁止重定向，不自动执行发现的工具。

## 接入流程

维护者审核地址并加入 `ONE_FEATURE_MCP_ENDPOINTS` 或 `ONE_FEATURE_HTTP_ENDPOINTS` → 管理员在智能体编辑器选择接入方式 → 绑定本人的测试凭证（若需要）→ MCP 发现并选择工具/HTTP 导入定义 → 保存并试运行 → 认定 → 指定账号上架 → 使用者绑定自己的凭证后运行。

提供公开合成 MCP 服务用于无第三方接口时验证传输链路；不访问业务数据、不调用模型、不反射秘密、不自动发布任何功能。

## 验证

凭证加密/跨空间/跨用户/跨地址绑定、序列化不泄密、鉴权头仅送往绑定地址、MCP JSON/SSE/协议及定义漂移、恶意地址/重定向/超时、发现不执行、撤权停止、原 HTTP/个人分享回归、生产构建。真实第三方效果留作集中验收。

协议参考：[MCP transport](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)、[MCP tools](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)。只读提示是供应商提示，不代替官方语义审核。
