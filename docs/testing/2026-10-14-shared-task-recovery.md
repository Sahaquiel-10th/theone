## 范围

修复工作台任务、独立功能运行和 Notion 保存核对之间的恢复差异。供应商响应速度、模型质量和价格配置不在本次变更范围内。保留原任务、附件、用量与较早重复要求；测试使用合成模型和隔离浏览器数据，不重发用户已完成的废盐合作方案。

- 自动测试覆盖公开路由、工作空间/用户隔离、Key 校验、附件来源、价格授权、取消与重复提交；模型调用使用合成响应，测试不依赖供应商。

- 发布结果以该提交对应的 GitHub Actions 部署记录和线上健康检查为准；本记录不把隔离测试等同于全部功能的供应商实测。
