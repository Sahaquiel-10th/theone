# ONE Mac 静态网页预览验收

0.4.13 增加 ONE 自己管理的本机静态预览，不改变 Codex 沙箱。网页入口在事情和工作台的执行详情内。选择授权文件夹中的 HTML 相对路径，启动后打开预览，也可停止；每台电脑同时保留一个预览，新预览替换旧预览。

## 范围和权限

只提供 UTF-8 HTML、CSS、JS、SVG 文件，每个文件沿用本机文件工具的 2 MB 上限。预览限制在入口文件所在项目目录，不展示目录，不支持上传，不执行工程命令，不支持图片等二进制资源。监听地址为 127.0.0.1，自动选择空闲端口；地址带随机访问标识并校验 Host。符号链接、隐藏文件、越界路径沿用受限文件工具的拒绝规则。

拔掉 Key、变更授权文件夹或驻留连接退出时停止，最长持续 30 分钟。新预览不会停止独立 Codex 任务。浏览器禁止跨站资源和接口请求；此能力不是对网页所有浏览器行为的通用隔离。Vite、Next、Node 工程服务，以及 Windows 预览未实现；Windows 仅同步启动器版本，不声明工程执行或预览验收通过。

## 0.4.14 修复及发布前验证

代码确认了一个可导致预览启动后失联的机制：0.4.13 的 serveProofs 接收循环直接等待监听启动和 HTTP 校验，最长超过 Key 验证的两秒期限；同期受保护请求可能触发验证超时，关闭连接及预览。没有首次端口 56627 对应的完整时序日志，因此这是已修复的机制，不是该次事件根因已经得到唯一证明。

0.4.14 将预览准备移到独立任务与串行所有者，保持接收循环处理 Key 验证。断开连接仍停止预览，未放宽沙箱或文件授权。停止或替换期间晚到的启动结果不能确认成功；服务器拒绝同设备重叠的预览变更。新增有 Key 验证、工作区、用户、安装实例和任务归属校验的状态查询。页面每三秒查询当前预览，有效地址不匹配、停止或连接无法确认时隐藏旧链接；旧启动器不能确认状态时明确提示升级。目录选择按钮调整为使用此文件夹。

类型检查、生产构建、应用测试 531 项（530 通过，1 原有压测跳过）及 Windows Go 测试通过。Swift 6 严格编译和原生 HTTP 测试通过，增加了真实监听器替换、停止状态、移除 Key 后状态失效，以及模拟超过两秒的慢校验中立即停止、晚到结果不得恢复预览的回归测试。状态路径的跨工作区、用户、设备及安装实例隔离测试通过。

发布网页不等同于更新本机启动器。本机当前仍为 0.4.13；0.4.14 安装后，需再从真实 ONE 页面验收首次启动、连续打开、停止后链接撤除、拔盘与插回、目录变更。不在本节宣称新版真机验收完成，也不开始七项新交互方案。
