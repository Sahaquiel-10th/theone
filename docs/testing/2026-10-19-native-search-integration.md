# 原生联网搜索接入

## 实现边界

- ONE 的 `web_search` 仍是统一能力，主对话和后台任务均经同一个服务端适配层查询。原生搜索默认复用已启用的兼容聊天模型；可通过 `WEB_SEARCH_MODEL_ID` 固定到已有模型编号，不硬编码新的模型或价格。
- `SEARCH_PROVIDER=native` 使用现有供应商原生搜索；`none` 可关闭。保留原有 `tavily` 适配供以后显式配置，本轮不购买服务，也不在原生搜索失败后悄悄切换供应商。
- 接口仅向审定的固定 HTTPS 地址发送最小公开搜索词，不发送聊天历史、知识正文、附件、模型自定义提示词或本机文件。网页内容仅作为不可信参考资料，不授予操作权限。
- 返回成功必须同时有完整 Response、真实已完成搜索调用、可用来源和摘要。普通文字声称已搜索或只写几个链接不能通过。引用优先使用结构化 annotations，其次使用实际 sources；过滤凭证参数和明显截断的地址，不在 ONE 服务端抓取任意返回网址。
- 每次查询绑定用户、Workspace、对话、正在处理的请求及 Key 证明。计费前重新验证绑定和预算，返回后再次验证，不能借另一个人的对话或请求查询、记账或取回结果。
- 模型 Token 按现有价格快照记录实际用量，计入当前主对话／任务预算，不增加搜索单价，不改既有价格。检索上下文的预留只是上限，不是固定收费。
- 默认 45 秒覆盖请求及响应体；明确限流或网关临时拒绝时最多重试一次。已被接受但断流的查询不自动重放；缺失来源、不完整响应和缺失用量不会冒充成功。
- 搜索步骤沿用对话进度，不为每次调用建立便利贴。未完成时由 ONE 说明未核实及继续查询的下一步，旧版对话入口也不因搜索失败直接丢掉整个回答。
- 浏览器能力响应只提供搜索是否可用，不泄露供应商名称或凭证。

## 配置

```dotenv
SEARCH_PROVIDER=native
WEB_SEARCH_MODEL_ID=
NATIVE_SEARCH_TIMEOUT_MS=45000
WEB_SEARCH_MAX_RESULTS=5
```

已有环境如果明确设置了 `SEARCH_PROVIDER=tavily`，发布后需由运营切换到 `native`；不得把代码默认值改变当成线上配置已经切换。无需更新或回收 ONE Key。
