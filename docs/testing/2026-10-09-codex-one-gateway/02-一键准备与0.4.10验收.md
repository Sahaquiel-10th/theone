## 用户操作与边界

点击后先回应，电脑上的确认窗口说明来源、版本、大小和安装范围。下载、校验和启动检查通过状态查询呈现，不让一个网页请求一直等整个下载；页面刷新只查询，不自动重复安装。拒绝或中断明确反馈，不开始业务任务。安装只在当前电脑的 ONE 专用目录，工作文件夹授权仍单独选择。

Mac 原生 Local Agent 继续保留；本批工程执行只接 Codex。Windows 启动器版本同步到 0.4.10，既有文件执行与更新流程不变，未声称新增 Windows Codex 一键安装或通过 Windows 真机验收。

## 安装与执行保护

工具清单使用独立种类 `one-managed-executors`，不能用启动器清单代替。沿用现有发布公钥验证签名；下载地址限于 Key 所绑定 ONE 站点的 `/executor-downloads/`，不接受重定向、Cookie 或供应商凭据。

下载按签名大小限流，摘要匹配后才解压。压缩展开受大小与时间限制；只接受常规 USTAR 文件，拒绝链接、路径穿越、重复文件、PAX 和设备节点。许可材料保留在安装目录。新版本暂存、启动检查通过后提交独立版本目录，最后原子切换指针；失败保留旧指针。任务运行、ONE 升级、工作目录选择与工具准备互斥，重复点击不会并行安装。安装后再次校验文件摘要。

工具准备前后不自动执行任务；Key 拔出会阻止提交凭证校验，旧工具不被破坏。重新连接后查询真实安装状态，而不是仅凭“下载结束”报成功。断点续传不是本批交付：下载中断后可以明确重试下载，不能把半包当成已安装。
