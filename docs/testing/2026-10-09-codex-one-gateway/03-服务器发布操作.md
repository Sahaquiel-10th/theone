# 0.4.10 启动器与 Codex 工具发布操作

本批只发布启动器和签名工具包。统一工程网关仍默认关闭；下面的操作不改模型、售价、成本或用户任务历史。网站代码的发布不能替代这些制品发布，也不能替代电脑实际运行 0.4.10 的验收。

## 上传和校验

将本机 `output/theone-local-execution-0.4.10.tar.gz` 上传到服务器 `/home/ubuntu/`。这份联合包约 252 MB，包含双平台启动器更新和 Mac 两种架构的 Codex 工具包，不包含发布私钥或供应商凭据。

在服务器终端执行：

```bash
(
set -e
printf '%s\n' 'c18d1af5dbd06eb8d72c6c6449a5ec7f135fe392c17e3af4a1f57ec772962d11  /home/ubuntu/theone-local-execution-0.4.10.tar.gz' | sha256sum -c -
release_stage=$(mktemp -d /tmp/theone-local-execution-0.4.10.XXXXXX)
tar -xzf /home/ubuntu/theone-local-execution-0.4.10.tar.gz -C "$release_stage"
sudo bash /srv/theone/current/deploy/install-runtime-update.sh "$release_stage/one-runtime-0.4.10"
sudo bash /srv/theone/current/deploy/install-codex-tools.sh "$release_stage/one-codex-tools-0.160.1"
)
```

预期先出现 `VERIFIED_VERSION=0.4.10`，随后工具签名与文件摘要通过，最后出现 `Codex tools published`。工具首次发布会在请求检查通过后重启一次服务；遇到未结束请求时保留运行中的服务，不删记录、不强制重启。发布失败须保留输出排查，不能把包上传成功当成安装成功。
