## 结果记录

使用 `results-template.json` 新建每轮记录，填写旧路径或新路径、实际源码与启动器版本、平台、模型、任务与会话编号、用量记录和成果证据。未执行项保留 `not_run` 与 `null`。

每次运行至少记录以下指标。

- 首次提交到可交付结果的状态与总耗时。
- 全部实际模型调用和电力结算，未知用量保持待核对。
- 用户提供资料、授权、决策和手动重试的次数。
- 断线及恢复后的原任务与原会话标识。
- 实际文件或页面的新建、更新次数。
- 成果、任务详情、主对话与刷新后的状态。

对照报告按实际执行结果填写样本数和成功率。协议合成响应与真实模型供应商测试分别记录。新增模型按其声明支持的输入类型运行相应用例。
