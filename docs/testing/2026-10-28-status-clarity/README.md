# 主对话等待区与右侧状态复查

日期：2026-10-28。桌面范围；沿用光学玻璃、分裂和融合、注意力 logo，不改模型调用、费用、权限或用户数据。

## 发现与修改

| 位置 | 发现 | 最终处理 |
| --- | --- | --- |
| 主回复等待 | 按等待时间自动填充的伪进度条，与实际完成度无关；多层旁白，停止按钮远离状态 | 删除进度条与随机旁白，单行真实阶段、实际等待时长、停止按钮；完成短暂显示勾；失败保留重试且不透出原始异常 |
| 任务动态 | 数量旁的“处理期间可以继续聊天”与卡片状态重复；状态和操作不在同一文字轴 | 头部只计数，卡片按图标/标题和状态/箭头排列，操作对齐正文；暂停、补信息、失败等不被旧 phase 覆盖 |
| 任务操作 | “重试”实际只打开详情，“忽略”实际只收起提醒 | 改成“查看并处理”“收起提醒”，保留回执捕获与停止隔离 |
| 接管任务 | 没有任务被解释成“电脑空闲”；“直接告诉 ONE”未说明操作入口 | “暂无接管任务”；指向主对话输入框；主操作仅移动注意力并聚焦现有输入框，保留草稿、功能、附件，不触发执行 |
| 本机状态未确认 | 首次读取或接口失败不能当作无任务/空闲 | “本机任务状态尚未确认”，提供刷新和本机设置 |
