# 原生搜索探测与工作文件夹文案

## 边界

- 原生搜索通过独立操作员脚本验证，不打开用户任务、不查私人知识、不读本地文档。
- 仅读取已有模型配置；不改供应商、密钥、价格、用户电力账本或 Codex 权限。
- 使用公开 MDN 定位问题。无自动重试；供应商可能按实际请求产生费用。
- 只有 response.completed、已完成的 web_search_call 和来源链接同时存在才通过，不能把模型自己写出的链接当成搜索证据。
- 日志仅保留状态、模型标识、请求编号、用量和有限来源 URL；不输出密钥、上游原始报错或正文。

## 执行

在应用目录、加载原有生产环境后执行：

```sh
node --import tsx scripts/probe-provider-search.ts --allow-supplier-call
```

如供应商明确不支持新版工具，可另行执行一次兼容版本：

```sh
node --import tsx scripts/probe-provider-search.ts --allow-supplier-call --preview
```

脚本不自动回退。若有多个非默认 GPT 配置，应显式指定 `--model-id=...`，不擅自替换模型。

## 文件夹体验

- 设置主标签、按钮和本机选择器统一使用「ONE 工作文件夹」。
- 权限解释移到选择按钮旁的「!」按钮，可用键盘打开和关闭。
- 保留「选择后允许文件工具读取、创建及按要求修改」的真实说明，不声称全盘授权，也不声称 Codex 的全部读取范围由选择器决定。
- 不更换用户原有目录，不改变目录保存逻辑、沙箱、命令联网或工具白名单。
- 浏览器文案随网站部署生效；Mac、Windows 系统选择窗口的文案需对应启动器更新。
