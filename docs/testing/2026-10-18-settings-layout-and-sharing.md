# 设置布局与页面内确认

## 范围

- 设置采用独立栏目导航；个人资料、功能授权、使用说明、新手引导、默认模型和账号安全分卡片显示。
- 旧说明改为独立历史列表，阅读窗口使用 HTML dialog 顶层展示，避免被历史列表或任务面板遮挡。
- 分享、付费重做说明、Notion 重新授权使用页面内确认。保留原有隐私、费用和权限说明，未改变服务器授权或计费逻辑。
- 已验收的新手引导文案、固定工作流及生成提示词不变。

## 本地验证

- TypeScript 检查、生产构建和差异空白检查通过。
- 全量测试：867 通过，1 跳过，0 失败（868 项）。
- 使用真实 React 组件和合成 API 的浏览器验收：旧说明列表 → 阅读 → 分享确认可逐层返回；取消和 Esc 不提交分享；确认后只提交一次模拟请求。
- 弹窗初始焦点在取消按钮，Tab 保持在弹窗内，Esc 后恢复到触发按钮。
- 付费重做取消时保留用途选择，发送 createGuide:false，只保存设置，不启动生成。
- 390px 宽度下，导航改为横排、设置卡片单列；恢复桌面视口后为分栏布局。

## 发布后只读验收

打开设置的四个栏目、已有说明和旧说明，打开后取消分享。不生成新说明、不创建真实分享链接、不提交密码、不更换目录、不安装工具、不重新授权连接。
