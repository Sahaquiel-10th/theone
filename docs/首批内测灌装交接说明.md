# 首批内测灌装交接说明

当前候选出厂版本：Mac / Windows 均为 0.3.8。TOMATO ONE（小星）的双系统在线更新已完成，回盘后的凭证、双平台文件和文件系统完整性检查通过。首只全新出厂样盘仍须验收，之后才按同样流程逐盘制作。

## 给灌装负责人的操作说明

1. 在 ONE 项目目录核对工作区，保存自己的未提交工作，再执行 `git pull --ff-only`。确认 `config/runtime-version.txt` 为 `0.3.8`；不要使用以前单独拷贝的灌装脚本或旧安装包。
2. 使用统一入口 `npm run provision:one-key`，它会从当前项目构建双系统启动器。生产 Mac 需有项目依赖、Swift Command Line Tools 和 Go。
3. 每只空白 U 盘使用 FAT32 + MBR；按当前卷路径、容量、实物标签核对目标。不要照抄 `disk4` 等设备编号。建议一次只插一只待灌装盘。
4. 由超管为正确用户签发独立 Key，给出凭证文件路径与实物序列号。不要把小星或超管的凭证复制给其他用户，不要把私钥正文写入台账。
5. 运行下列命令；把示例路径替换为实际文件和卷路径：

```bash
npm run provision:one-key -- --credential "/凭证目录/用户.json" --dry-run
npm run provision:one-key -- --credential "/凭证目录/用户.json" --volume "/Volumes/ONE-001"
```

6. 必须等到输出“双系统灌装完成”，确认两端显示 0.3.8、文件系统检查通过。任何错误均先停止，不能自行略过校验继续发货。
7. 第一只新盘先做 Mac 和 Windows 双机验收：正确账号登录、首次称呼引导、知识连接、发消息、拔出拦截、重插自动恢复。Windows 休眠和重启回归也要记录。通过后继续制作该批次。
8. 每只盘记录用户、序列号、设备 ID、出厂版本、日期和验收结果；后台赠送约定的内测电力，安全推出并贴标。

旧版单系统脚本和新盘统一灌装器不用于覆盖已使用的超管盘。超管 Key 需单独核对旧版本和文件布局，保留原凭证后选择兼容的在线升级或受控维护。管理员角色来自服务端绑定，更新启动器不会更换角色。

2026-09-17 只读检查：ESD-USB 的 Mac 启动器为 `ONE.app`、版本 0.2.8，属于旧布局。不能承诺网页直接更新；需要一次保留身份凭证的双系统启动器迁移，不应格式化该盘或用空白盘灌装命令覆盖其现有文件。
