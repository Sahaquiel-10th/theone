- Skills：独立任务、后续任务、手动重试、后台试运行和主对话功能调用均不再要求金额或高倍率确认。仍按服务器当前发布版本冻结价格、检查功能资格和来源。

账户余额仍在原子事务中预留与结算，余额不足不调用供应商。身份、ONE Key、跨空间隔离、来源授权、访问期限、技术并发/重试次数限制保留。真实商业服务方案、已发放服务资格/赠送额度与公司费用权限属于独立的付款和访问约定，本次不改变其价格、付费归属或权益。

## ima 重连稳定性

相同账号、相同 Client ID / API Key 重连，先验证官方接口，再保留原密文与已选择的知识库范围；新出现的知识库不会自动加入。这样不再仅因随机加密密文变化而让已绑定课程授权失效。

真正换凭据、换所有者、撤销连接或改所选范围，原课程引用仍失效，需老师重新确认。未绕过课程资料授权，也不扩展到其他账号或空间。

已有检索链路继续使用精简关键词、读取文件正文、原文片段引用。未检索到资料、正文不可读与授权失效仍分别报告；“连接成功”不是“任意问题都能命中”的保证。
