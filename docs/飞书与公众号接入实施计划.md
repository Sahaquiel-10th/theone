# 飞书与公众号接入实施计划

用户于 2026-09-21 批准本阶段。先完成飞书读写闭环，并行准备公众号第三方平台资格。Local Agent 等待 ReAI 测试，不改启动器。

## 用户体验

- 飞书：连接 → 官方授权；企业尚未安装时，引导管理员安装 ONE。普通用户不填写开发凭证。
- 首个闭环：按需搜索用户有权限的云文档 → ONE 基于引用生成回答 → 用户预览并确认 → 新建飞书文档 → 返回回执。
- 第一版选择新建文档，不覆盖原文，不同步整个知识库。多维表格另行验证字段映射后增加。
- 公众号：平台型第三方平台 → 目标公众号管理员扫码授权 → 确认账号权限 → 保存草稿。正式发布单独验收，不自动群发。

## 前置资格（不能由代码代替）

### 飞书

1. 在飞书开放平台创建 ONE 应用。自己企业内测可先使用自建应用；面向不同客户企业必须选择平台支持的跨企业应用分发方式并完成相应发布审核，不能把一个企业的自建应用直接当成通用授权入口。
2. 开通文档搜索、文档读取、文档创建及写入、用户身份与离线授权的必要权限；以实际应用后台可选权限为准。
3. 配置 ONE HTTPS 回调地址、隐私政策和服务协议。
4. 企业管理员安装/审批、设置可用范围；用户再完成自己的身份授权。应用权限与文档分享权限分别检查。
5. 取得 App ID / App Secret 后仅配置在服务器，禁止写进网页、聊天或 U 盘。管理员安装入口也由服务端配置，不猜测地址。

### 微信公众号

1. 微信支付商户号、支付 App ID、API v3 密钥不是第三方平台资格，不能复用作授权凭证。
2. 微信开放平台创建 **平台型第三方平台**，配置开发资料、授权与消息回调、校验 Token、消息加密密钥、所需公众号权限集。
3. 未全网发布时，将测试公众号加入授权测试列表；由该公众号管理员扫码确认。
4. 核对公众号类型、主体、认证状态和草稿接口权限；能授权不代表拥有全部接口。发布接口另受主体/认证限制。
5. 收到 component_verify_ticket 后安全存储；取得预授权码；以授权码换取 authorizer 凭证并绑定精确 ONE 用户与 workspace。
6. 草稿必须包含明确标题、正文与公众号已有的有效封面素材。不能假设只有纯文本就能创建文章草稿。
7. 先实测授权、刷新、草稿保存和撤销；之后才申请/验证发布权限及全网发布。

## 验收

- 两个 ONE 账号、两个平台账号验证隔离；篡改 sourceMessageId/操作编号不得跨账号读取或写入。
- 单次 OAuth state、过期与重放、重连和断连竞态、加密凭证、刷新失败。
- 写入前验证 Key 在场；明确确认本次内容与目标账号；记录回执；网络结果不明时不盲目重试。
- 企业未安装、管理员未批准、用户未授权、资料无权限分别提示。
- 当前电脑更换不会要求重复平台授权；本机权限不扩展。
- TypeScript、单元/集成与跨租户测试、构建、diff 检查；真实账号验收不能用模拟通过代替。

### 2026-09-21 配置与测试记录

- 飞书实现使用官方 OAuth PKCE + OpenAPI，协议依据官方 MCP 0.5.1 的授权实现与飞书接口文档。无需终端用户安装 CLI。
- 服务器需设置 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_OAUTH_SCOPES`、`APP_ORIGIN`；缺少配置时连接按钮不可用，不触发召回。
- 回调：`https://theone.aiarrival.cn/api/knowledge/connections/feishu/oauth/callback`。
- 首轮权限候选：`offline_access search:docs:read docx:document`，还需在应用后台确认用户基本信息和文档元数据查询所需权限；最终以后台批准及真实测试为准。权限不足不能用企业 token 或他人授权替代。
- `FEISHU_INSTALL_URL` 填平台实际提供的 ONE 安装链接，仅接受 HTTPS 飞书域名。未提供时只展示管理员开通指引，不编造安装链接。
- 搜索目前只读取新版 docx，关键词搜索，不宣称全账号语义搜索或全部文件类型。返回正文最多 24000 字符；新建回答文档最多 40000 字符，纯文本，不保留 Markdown 富文本样式。
- 每次保存绑定当前飞书账号、ONE 用户、workspace 和服务端回答，默认不允许同一回答反复创建。回执持久化在该 workspace 的连接记录中。结果不明保留文档编号（若已取得）并禁止盲重试。
- 本地模拟验收覆盖 OAuth 重放、加密存储、跨 workspace 拒绝、写回去重与超时不重复。尚未完成真实飞书账号验收。
- 用户提供：`降临科技` 为已认证服务号，优先作为完整测试账号；`嘿哈主教` 为未认证订阅号，另测草稿权限。
- 微信新增草稿官方文档：支持第三方代调用，权限集 **11 或 100**；适用范围列公众号和服务号，但本页未细分未认证个人账号资格。必须在测试授权后检查实际权限并试存草稿，不将发布限制直接套用到草稿。
- 公众号需用户确认是否已创建平台型第三方平台。当前未取得该配置，不发起授权、不创建草稿、不发布文章。
