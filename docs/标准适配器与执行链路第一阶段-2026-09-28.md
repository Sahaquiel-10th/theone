# 标准适配器与执行链路：第一阶段

## 目标及上线边界

先实现并测试一个只读 HTTP 纵向切片，不等全部接完才测试。本阶段是服务端技术底座，不是可用功能目录或完整 MCP/OpenAPI 平台。

已实现：受限 OpenAPI 定义解析、输入和输出校验、固定 HTTPS 调用、超管测试执行、请求去重、空间隔离与持久化审计回执。没有修改个人分身、个人工作台或 Key 驻留程序。

**生产测试接口登记列表目前为空。** 没有接入真实外部供应商、没有收费、没有新增普通用户入口或后台测试按钮。调用测试入口返回 `PILOT_NOT_READY`；官方配置页面仍显示运行未开放。禁止为了演示填入虚假的“连接成功”。

## 支持的标准子集

- OpenAPI 3.1.x 的 JSON 对象定义，单个 HTTPS 域名根地址。
- 仅 GET、固定路径、query 参数；字符串、有限数字、安全整数和布尔值。
- 返回 200 application/json；扁平对象、固定字段及必填项，不接受未声明字段。
- 不支持鉴权、凭证、POST、文件、流、异步任务、路径变量、外部引用、服务器覆盖、复合 schema、数组或任意脚本。未知执行相关字段和未支持约束直接拒绝，不能忽略后假称支持。
- 文档里的地址必须属于代码审核登记的**精确接口地址**；导入器不会下载文档或解析远程引用。导入不是批准。
- 后续会扩展兼容范围；当前不能宣传“任意标准接口免开发接入”。参考规范：https://spec.openapis.org/oas/v3.1.1.html 。

## 网络边界

默认每次调用最长 10 秒（包括 DNS），最大响应 256 KiB；禁止重定向，只支持公网 IPv4。校验 DNS 返回的全部 A 记录，连接固定使用通过检查的 IP，同时按原域名校验 TLS；不复用连接，不透传浏览器 Cookie、令牌或代理。

拒绝私网、回环、链路本地、常见云元数据、保留地址；IPv6 尚未支持。GET 不天然等于没有副作用，真实接口必须经过人工语义审核。服务端信任的适配器定义仍不能由浏览器、模型输出或上传文件注册。

## 测试执行合同

`POST /api/admin/official-features/:id/pilot` 仅超管 + Key 在场；主体和空间由既有认证中间件确定，不接收浏览器提供的付款人、空间、工具地址或身份。

服务端登记绑定功能 ID、已认定版本、工具定义摘要、`free_test_only` 策略。需要同时满足：用户启用且为超管、属于当前空间、功能未停用且版本相同、工具定义未变更。调用前后再次核验，执行期间停用后不返回内容。

流程：校验参数 → 原子申领 operationId → 再查权限 → 执行 → 再查权限 → 记录状态 → 返回结果。没有调用模型，因此没有额外模型消耗；不支持付费外部接口，不能把零费用测试策略复用于商业运行。

同一空间、用户、operationId 只执行一次；同一 ID 换输入报冲突。重试返回原状态而不是重新执行。执行中崩溃留下的请求在 30 秒后显示 unknown，不自动补调。每人同时最多一笔新测试，每小时最多 60 笔。

回执写入既有 audit_logs，含 workspaceId、用户、功能版本、工具摘要、状态、耗时、费用 0；不记录参数、返回原文或远端错误正文。返回原文仅给本次调用者，重试不会从日志恢复正文。该策略仅适用于小规模测试；正式用户任务需独立任务结果存储及保留策略，不能把审计日志扩展成聊天或私有资料仓库。

无需数据库迁移，审计随现有备份。沿用当前单进程 Store 原子变更边界；多副本部署前必须改成数据库唯一约束/任务申领机制，不能直接水平扩容。

## 验证与下一步

自动测试覆盖两种不同参数结构、编码、输入/输出约束、恶意定义、地址防护、DNS 固定连接、重定向、异常 JSON、结果上限、超时、错误脱敏、重复/并发请求、跨空间隔离、执行中停用、Key/角色拦截及默认关闭。

网络成功/异常测试使用隔离传输桩，不代表真实供应商联调通过；没有运行真实付费模型，没有访问内测用户资料。

后续顺序：

1. 选择一个明确授权、无费用且不涉及私人数据的实际测试接口，登记服务端绑定，用真实测试账号验证一次完整任务；验收前不向用户开放。
2. 补后台测试输入、结果及回执列表（折叠、分页）。再按真实接口所需逐项扩展标准 schema、加密凭证引用和精确用户授权绑定。
3. 在相同授权及回执合同下接 MCP，选择批准的工具和版本，发现清单不自动放权；不扩展公开分身权限。
4. 商业执行另接预算预留、结算、收费版本和用户资格；再做正式目录灰度，而非沿用免费超管测试入口。
