# 课程资料与使用体验修正（2026-11-05）

## 本次范围

- 课程资料只关联已授权知识库。移除课程讲义原文与教材上传入口；保留工具中的私有试卷、评分参考和学生作业原件。
- 新课程默认 `sourceMode: knowledge`；编辑课程明确切换该模式。旧正文、附件及历史快照不被批量删除；知识库模式不会把它们作为学习上下文。
- 工作台删除底部课程计数与“旧版准备”入口。仅退休本账号、当前工作区、明确 v1 格式的旧本机准备缓存，不删除服务器课程或其它用户草稿。
- 工具顶部明确显示当前绑定课程与切换按钮。
- 课程 AI 用量改为独立原生弹窗，展示累计已用、进行中预留、累计上限与按该上限剩余电力。保存和确认不会执行 AI。教师手动操作可选择按账户余额结算或受课程上限限制；新课程默认前者，旧课程不自动解除上限。公开学生 AI 始终受课程累计保护上限约束，教师操作也计入累计使用；不会新建另一份独立计数。钱包预留、价格与模型不变。

## 保存与检索修复

原预览 API 在校验整连接范围确认后将 `confirmed` 归一化掉，未保存表单再次提交时因缺少确认被拒绝。现在该标记只在明确确认的预览回执中临时携带，最终保存时仍移除。

预览使用课程名作为可修改的查询起点，并可输入具体问题。区分实际取得片段、当前问题未命中、未选知识库文件范围、命中但正文不可读、授权失效及调用失败。连接正常不等于任意查询都有结果。

ima 课程绑定额外固定原客户端身份、凭据所有者与已选知识库 ID；预览后改账号或范围不能沿用旧确认。无法证明原范围的旧引用需明确重新核对，不自动扩大授权。

## 回收站

增加显式“彻底删除”，不设置后台到期自动清空。流程为只读影响预览 → 明确确认 → 保存原请求编号 → 删除回执核对。只接受当前用户和工作区已在回收站的准确版本；正在执行、结果不确定、解析中或财务待复核的内容不能删除。

删除课程教学记录及无其它引用的私有文件、提取片段；保留被其它教学快照、对话、任务或行业流程使用的文件。保留账本、用量与审计。清理文件失败会保留待清理回执，同请求可在进程重启后继续核对，不重新删除其它内容。

API：

- `POST /api/teaching/purge/preview`：`items`，返回 `impactHash` 与影响数量。
- `POST /api/teaching/purge`：原 `items`、`impactHash`、`requestId`、`confirmed: true`，返回公开回执。
- `GET /api/teaching/purge/:requestId`：读取原回执。
- `GET /api/teaching/courses/:courseId/usage`：准确归属范围内的累计计费用量，只读，无模型调用。

## 可选上限与已有授权

`teacherBudgetMode` 为 `balance` 时只允许教师主动操作跳过课程上限，ONE 账户余额与预留仍检查；为 `course` 或旧课程无此字段时维持原限制。只有明确提交该字段才能修改旧课程规则。公开请求有学生 session，无论教师模式均检查课程累计上限。新课程零保护额度时教师可工作，学生 AI 仍不可开放；普通作业收件和在线答题不受影响。
