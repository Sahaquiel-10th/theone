# ONE 聊天式新手引导第一版

本轮用户批准：能选就不打字；ONE 对用户的日常保持好奇，前几轮预设，随后按回答动态追问。资料足够后制作定制说明书，主对话恢复正常，不要求先完成另外一件实际工作。

## 体验

- 新账号从主对话开始；称呼可点选现有昵称、朋友或自填，不修改登录账号。
- 首次服务端随机持久化八个人格之一：中二病、高冷傲娇、霸总、嘴欠损友、元气小狗、古风军师、赛博机器人、疯科学家。可换人、调三档强度及一行自定义人设，设置中随时可改。
- 日常方向预设；场景和习惯两轮结合已确认内容，由独立模型调用生成问题与少量文字回答选项。真实操作不由模型任意生成。
- 知识连接打开已有设置，回来刷新实际授权来源；允许稍后连接，不声称已读笔记正文。
- 资料齐后登记首次赠送说明书任务，复用已有持久执行队列、预算和恢复机制。收集结束和成果交付分开记录。
- 完成或暂停后恢复主对话输入，初次聊天仍可回看。正在编辑的实际工作要求可以带回主输入框，由用户发送。
- 已在执行的旧版实战引导保留原流程。既有欢迎礼物或未决任务不会被自动替换、重做或另收费。

## 状态和接口

`GET/POST /api/me/profile/curious-onboarding`，按认证账号与空间授权，禁止客户端选择其他 owner。

引导状态为 active / paused / completed；说明书另有 preparing / queued / running / completed / failed / cancelled。请求带 sessionId、revision 和 requestId，旧选项失效，相同请求不重复调用模型或派任务。

模型请求前持久登记 pending；没有结果时 GET 保持 busy，显式恢复才持久化备用问题并递增 revision。迟到结果不能覆盖新轮次。

临时引导指令只属于专用请求，保留平台安全规则，不修改共享模型提示词。普通聊天逐轮取得本人称呼和人格，不取得引导控制指令或整段引导历史。专业交付遵照任务要求，不强制套用聊天人格。

说明书使用已确认事实与实际能力标签的冻结快照。快照及引导全文不通过普通 profile、管理员用户列表泄露；本人设置可编辑自己的自定义人设。
