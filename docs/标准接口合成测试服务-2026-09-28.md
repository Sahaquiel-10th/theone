# 标准接口合成测试服务

## 为什么做

用户暂时没有现成接口，先做一个专门的测试接口，验证上一阶段适配器能通过真实网络完成任务。不是在执行器里返回预设答案：接口通过 Express 提供、部署后走公网 HTTPS，适配器仍做 DNS、公网 IP、TLS、响应格式和结果校验。

与主应用同进程、独立路由模块，没有新服务器或新端口。它是逻辑隔离的测试区，不是独立进程/容器沙箱；不应据此承诺第三方代码安全隔离。

## 测试区的安全边界

- 全部为固定虚构园区资料和库存，没有用户资料、数据库访问、文件访问、凭证或模型调用。
- 公共只读接口，无需登录，因为其中没有身份绑定资源。不能仿照此鉴权方式开放正式用户知识或工具。
- 不接受任意地址、任意文本、上传、写入、任意延迟、输出大小或脚本；不反射输入及请求头。
- 每进程整个测试区 120 请求/分钟，全局固定计数，不建立随 IP 增长的内存表；不影响普通业务路由。
- 用 `ONE_ADAPTER_SANDBOX_ENABLED=false` 并重启可关停；默认开启供本轮验收。正式灰度结束可关闭。
- 公网不提供慢请求/超大结果，超时和大小边界继续在隔离自动测试里验证，避免公开资源消耗入口。
- 此接口没有业务收费，也不消耗模型电力，但仍有少量服务器请求和流量成本。

## 固定接口

根地址：`https://theone.aiarrival.cn/api/adapter-sandbox/v1`

| 路径 | 合法参数 | 用途 |
| --- | --- | --- |
| `/openapi.json` | 无 | 当前受限 OpenAPI 3.1.1 文档 |
| `/lookup` | `topic=meeting/printer/missing` | 字符串参数、有结果、无结果 |
| `/inventory` | `itemId=101/102/999` | 整数参数、库存数量、无库存 |
| `/probe` | `scenario=ok/unavailable/invalid-json/wrong-schema` | 正常、503、损坏 JSON、输出结构异常 |

测试数据不会伪装成真实知识来源；正常响应均带 `synthetic: true`，响应头带 `X-ONE-Synthetic: true`。

## 验收命令

在项目根目录执行：

```bash
npx tsx scripts/check-adapter-sandbox.ts --live
```

脚本只调用代码内固定的公网测试地址，不接受任意远端地址。使用真实默认 HTTPS 传输和现有执行服务，检查查询命中/无结果、不同参数、错误状态及同一次请求不重复调用。身份、审批快照和执行审计只在脚本本地内存中构造，不登录或写入生产数据库；不会创建生产账号、赠送电力、修改收费或审批生产功能。

成功应输出六项 PASS 和 `LIVE_SANDBOX_OK`。部署前该命令可能收到 404；不能把部署前失败标作适配器验收成功。

## 能证明什么、不能证明什么

能证明：这个受限 HTTP 定义经适配器到已部署 HTTPS 服务再返回执行结果的网络链路工作正常，并对受测异常安全失败。

不能证明：后台 UI 已提供测试操作、真实用户鉴权/Key 端到端体验已验收、第三方 OAuth 可用、真实业务任务质量合格、付费接口结算完成或 MCP 已接入。生产官方功能登记仍不自动批准，超管 pilot 的服务端登记列表不因此自动开放。下一步可用这个固定服务做后台测试界面及注册/认定流程，然后再替换为真实业务接口。
