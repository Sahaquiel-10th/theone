## 本轮改动

1. 使用统一的精确用户、空间、Key、电脑准入判定。普通历史失败/已确认停止不占设备；真实运行和未知副作用仍保护。
2. 停止可幂等地重发给原 attempt/round。回执只补传原始记录；找不到原记录不冒充结束。
3. 选择器归属精确到本轮。停止关闭本轮窗口、等待准备退出后才报告终态，不能关闭另一任务的窗口。
4. 同 Key 的有效工作目录在新任务、重启后复用；目录失效明确反馈到设置，不隐式反复要求重选；取消更换保留原目录。
5. 主对话、任务详情与执行面板均区分“停止请求发出”和“已确认结束”。确认结束后可沿用同一任务继续；未知结束只允许核对和再次停止。
