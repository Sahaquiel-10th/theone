# ONE 桌面工作台：理解成本与信息层级审查

日期：2026-10-27。实施基线：`7ac6c26e71da52e9344009e0c27a7d84cf1a4e14`。

本轮围绕“用户要看什么、下一步能做什么、如何返回”逐页检查。保留已经确定的光学玻璃、石墨框景、主对话稳定位置、分裂与融合、超能力输入框，以及任务/本机权限和计费行为。

## 检查方式与证据边界

- 先检查用户的三张截图、实际路由与渲染代码，再保存修改前截图。改动在隔离工作副本完成，原有脏工作目录未重置或覆盖。
- 桌面预览使用真实应用组件与合成数据，实际通过内置浏览器逐项操作。所有截图保存后均打开检查。预览中的“合成”“不调用模型”等标记只解释测试边界，未当作线上文案缺陷删除。
- 修改前源码与校验清单在桌面 `ONE-UI备份/20261027-ux-clarity/before`；修改后源码、证据和说明保存在同目录的 after / evidence / README。
- 本次不在生产创建任务、分享资料、支付、修改价格或授权外部服务；合成访客页、管理员数据与本机状态不能证明这些真实业务动作已经成功。

## 逐项发现与处理

| 页面/路径 | 发现 | 修改与验收 |
| --- | --- | --- |
| 主对话 | 任务通知与正常回答同层级，同一任务有正文链接和底部按钮，状态、操作按钮反复出现 | 仅将精确服务器格式的任务报告显示为紧凑状态卡，每项一个任务入口；完整原文/复制/反馈可展开，正常 Markdown 与代码不被折叠。合成三任务报告已检查，正文与附件保留。 |
| 系统任务文案 | `goal_unfinished` 经下划线清理变成 `goalunfinished`；“接住/承接”等表达没有说明真实状态 | 自动摘要先过滤已知独立诊断行；原始诊断与完整记录保留。固定 UI 和实际调用的共享提示词统一表达排队、处理、未完成、待核对等事实，不承诺自动恢复。 |
| 功能列表 | 可用、已开放、作者、倍率、计费及选择说明反复占位 | 列表保留名称、用途、官方角标、查看详情与下一条使用。费用与使用范围移入详情。多选不会关闭选择器。 |
| 功能范围 | “我的功能/发现功能”请求同一个只返回已授权功能的 API，线上没有范围差异 | 合为真实的“可用功能”。没有新增目录 API、开通能力或绕过授权。合成 fixture 与真实 API 保持一致。 |
| 功能详情 | 简介、用途、限制、费用和运行入口平铺，缺少阅读顺序 | 介绍主栏按用途、可以完成、使用说明、限制与注意组织；费用、知识、工具范围为次栏。状态缩为介绍顶部小标记；官方用角标表达。 |
| 单独运行 | 用户不知道这会创建独立任务；打开后无收起路径，任务输入在长表单下部 | 改为“单独创建任务”，说明结果在运行记录。顺序为任务要求→偏好与材料→知识与工具→费用与开始。固定返回介绍入口；已打开的面板保持挂载。实际填写草稿与预算 0.8，收起再打开均保留。未提交真实任务。 |
| 功能运行记录/结果 | 继续/重试进入下一轮后缺少上一轮返回；同一运行记录再次打开可能无效 | 增加查看上一轮结果的本地返回；通过打开请求计数区分相同任务的再次打开。原 POST、幂等 operationId、计费确认与恢复规则保留。 |
| 工具连接 | 点入工具连接后还需点同名折叠；多条都叫“我的接口凭证”；未加载就显示为空 | 工作台内直接展示列表，区分加载/失败/真实空态；用服务主机和路径辨认，不显示 URL 查询、用户名或 fragment；保存/撤销后刷新。真实凭证从未输出。 |
| 任务与成果 | 进展/失败说明、恢复要求与普通对话抢空间，专业“回执”混入状态 | 状态先给一个结论，处理进度、完整记录和恢复要求可展开；本次预算及恢复按钮保留。列表状态简短，分页与明显返回入口保留。 |
| 分身列表/编辑/分享 | 独立页面仍引用旧 feature-shelf 样式范围；紧凑样式失效；嵌套材质在整层分裂期间被隐藏，出现黑底黑字 | 样式归属迁回 sharing-panel；修复分裂时的嵌套材质可见性、窄卡标题与分享状态；去掉叙述布局机制的旁白。继续采用列表→个体编辑→明确开放分享，新分身未分享。 |
| 设置：外观、个人资料 | 解释“布局相同/账号保存”等重复内容，时间城市表单过长 | 删除重复外观旁白，时间与城市按字段分组；账号退出入口移入设置，不丢失登出能力。 |
| 设置：帮我留意 | 未开启也展开整张高级配置，第一屏没有摘要 | 默认显示状态、主题摘要和编辑入口，需要时才展开；没有连接来源时给出“连接知识来源”，只导航既有设置，不新授予权限。 |
| 设置：本机执行 | 安装渠道、执行工具、版本详情与用户可用状态混杂 | 主状态区分已就绪、需要准备、连接未确认；工具与版本在详情中保留。 |
| 设置：知识连接 | 标题与状态重复，常驻“不调用 Notion AI”等实现说明；保存页帮助过长 | 唯一标题与状态同行；说明搜索已授权页面；“保存到 Notion”明确动作，复制链接方法和权限费用留在展开帮助。 |
| 设置：功能费用确认 | “功能单独授权倍率/授权门槛”难以理解 | 改为功能费用确认、超过设置倍率先确认；详情解释确认阈值与电力上限的区别。数值、校验、API 与确认 payload 未变。 |
| 会员与额度 | 需要确认剩余额度/到期/永久电力/使用记录是否有主次 | 实际检查合成会员页：剩余比例、期限、永久电力及账单分层清楚，保留现有结构；未点击真实付款。 |
| 历史对话 | 多余 YOUR FLOW、小型归档图标缺少可访问名称、登出混在对话管理 | 删除英文旁白，搜索文案简化；归档按钮包含对话名；登出移到设置账号区。 |

| 公开访客分身 | 需核对作者/AI 身份、费用归属、开场问题、进入聊天是否可辨认 | 独立合成页检查初始页与开始聊聊：身份、隐私与费用归属可读，快捷问题和输入明确。真实登录/支付/联系表单提交不在本次浏览器验证范围。 |
| 管理/公司 | 11 个管理入口平铺；公司知识连接直接显示英文状态 | 管理按账号设备、模型功能、用量记录分组；公司状态中文化，分区加清楚边界。只读合成概览/公司页面已检查；账号权限与款项操作未执行。 |
