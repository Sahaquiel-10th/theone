# 时间、公开搜索与主动关注 V1

## 交互契约

- 服务器校准当前时刻；浏览器只提供时区提示，用户保存的时区优先。每轮原始日期随 operation/workRun 保留，重试不重新解释“昨天”。城市为用户手填的常驻地，不是精确定位。
- 当前回答可使用 web_search；搜索是进度步骤，不单独创建便利贴。功能、任务和公开分身原有权限边界不变。用户说不联网、纯私人日期检索、分身禁止联网时不能提供公网工具。
- 公网查询不默认发送完整原话；检索器只联系固定 HTTPS 搜索上游，禁止跟随重定向，限制响应、结果数和正文长度。暂时性只读故障最多重试一次；无结果、未配置、失败分别返回，不能假称已查证。明显凭证、联系方式和已取得的私人长段落不能作为公网查询。
- 得到大脑 recall 当前没有日期过滤参数。保留来源创建/更新时间，查询带明确日期线索，向模型明确 strictFilter=false；创建时间不能冒充会议发生时间，不声称该日已查全。

## 主动关注边界

默认关闭。设置 → 个人设置 → 帮我留意，用户明确选择最多 3 个来源和 3 个主题，频率 1/3/6/12/24 小时，每日最多 1—12 次，默认 6 小时/4 次，22:00—08:00 免打扰。

这是主题语义检索抽样，不是全量增量同步。第一轮建立基线，后续新检索结果或内容指纹变化才形成合并提醒；不能宣传“已经检查所有信息”或“刚发生了更新”。只持久化主题、来源绑定、有限指纹和通知元数据，不复制知识正文。无新增则安静；失败不推进指纹，状态可查看。

后台每分钟检查到期配置。使用开启时的精确设备/installation 绑定；每轮实际读取前后重新证明 Key 和成员/来源授权，未连接则暂停。关闭网页不会停止已授权的检查；拔 Key、停用账号、撤销来源、暂停设置会阻止新读取或丢弃迟到结果。独立工作租约、每天次数和只读超时防止重入与无限等待。无模型调用，检查不扣 ONE 电力，但会消耗来源平台的查询配额。没有后台全盘/本机扫描。

新线索最多展示最新 5 条，存储最多 30 条。用户可整理重点、列待办、明天再说、先不用和全部已读。前两个动作只预填草稿，不覆盖已有草稿，不自动发消息、创建任务、发送或修改文件；用户实际发送后走现有分派与计费。通知的内容不是执行授权。

## 持久化与隔离

用户记录新增可选 contextPreferences / attentionStates，每条记录包含 workspaceId/userId；沿用 users 的既有 JSON 行存储，无共享迁移改写。通用 publicUser/管理用户列表不返回这两类私有配置。所有新路由使用 keyAuth，scope 来自服务端身份；忽略浏览器伪造的 workspaceId。查看通知时重新核对来源权限与账号绑定。

## 验收

自动：跨空间/用户、停用/撤销、断线、免打扰、每日上限、租约、重启指纹、首次基线、重复与稍后提醒、迟到响应、后台读取超时、HTTP 路由、私密配置序列化、时区/夏令时、真实调用与禁止联网、搜索故障/未配置与来源大小上限。

线上：设置页布局与保存、当前时间只读问答、一个公开搜索的真实来源和进度。主动关注默认保持关闭；真实个人知识提醒须由用户选择关注范围后开启，不为了验收擅自启用。
