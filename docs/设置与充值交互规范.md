# 设置与充值交互规范

## 本次调整

- 账号设置分为「个人设置」「电力与账单」。余额、充值、消耗不混入修改昵称与模型设置。
- 电力显示精确余额与比例条。比例 = 余额 /（余额 + 历史电力账本累计消耗），不是套餐容量，也不是可用次数；预占另行展示。统计只读取当前用户、当前空间的账本。
- 点击充值打开弹窗：人民币 5、10、15、20、50、100 元与自定义。自定义最低 0.01 元，最高 10000 元。付款前展示换算电力，生成订单后使用服务端快照。
- 弹窗打开且页面可见时，每 5 秒核对待支付订单，支付成功或关闭弹窗即停止；订单超过付款有效期停止自动查询，仍可手动核对。关闭弹窗不取消或删除订单，可在充值记录继续核对。
- 消耗、充值和流水切换展示，每页 10 条；编号、Token 和计费说明收进单条详情。价格放入单独弹窗，支持搜索和分页。
- 知识来源展示紧凑平台卡片，支持搜索与连接状态筛选，点击后显示该平台连接操作。保持既有授权与轮询协议。
- Key 绑定用户、赠送用户、默认模型、智能体固定模型使用搜索弹窗，每页最多 8 个选项。少量固定状态枚举仍可保留原生选择控件。

## 后续维护

- 会随用户量增长的列表，不采用无搜索的长下拉；历史明细不在首页无限追加。
- 重要金额保留单位与精度，订单号默认折叠，不用重复通知堆叠状态。
- 弹窗支持 Escape、关闭按钮、焦点约束；390px 窄屏和桌面都要检查。
- 本次不改变支付结算、商户配置、消费价格或 ONE Key 在场验证；无需更新 U 盘。

## 验证

本地隔离预览中检查了设置分栏、390px 知识卡片、充值档位、自定义 0.01 元换算、模拟支付成功自动刷新、120 个账号搜索与分页。预览未向微信创建真实订单。服务端新增统计接口覆盖未登录、跨用户与跨空间隔离测试。
