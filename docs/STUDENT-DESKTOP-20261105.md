# 学生学习空间 PC 布局

学生 `/learn` 使用完整浏览器宽度，课程侧栏与对话学习、历史游戏、上传作业、考试测验四个主入口；提交与反馈独立回看。保留教师班级与课程授权、课堂作品分配、原有上传与考试提交路径，未增加公开数据接口。

登录页、课程横幅和游戏场景使用压缩后的西湖意境插画；图为 AI 教学想象，非历史影像。游戏继续分离剧情与两枚行动按钮，保留五次选择、史实回顾和原有结局生成插画。桌面课程辅导采用左侧气泡记录、右侧问题与参考材料；小屏回落单列，不隐藏作业和试题。

验证：TypeScript、生产构建、前端单测、学生账号/课程隔离与故事相关测试、diff 检查。本地隔离账号浏览器检查课程导航、作业附件入口、考试单选和文字题提交回执、已发布教师反馈；未执行生产付费模型调用。
