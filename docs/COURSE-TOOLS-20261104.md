# 课程工作台：工具、课程与保存项

用户于 2026-11-04 确认以下产品结构后授权实施。此前围绕一门课程堆叠资料、提示词、阶段、活动与收件的长页停止作为主入口。

## 页面结构

- **课程工作台**：知识问答辅导、文字游戏构建、上传试卷、批改作业四张工具卡。全部、课前、课中、课后只筛选卡片。右上角为管理课程、添加课程。
- **管理课程**：课程列表、添加、编辑资料、课程回收站分别为页面。只管理名称、主题、文字、私有文件和已授权知识引用，不承担教学活动配置或学生收件。
- **打开工具**：选择课程；最近使用的有效课程可记住，但须在工具顶部清楚显示并允许更换。只展示该工具的已保存项及新建入口。
- **知识问答辅导**：设置引导 → 实际试问 → 分享。
- **文字游戏构建**：设置背景和玩法 → 实际试玩 → 分享。
- **上传试卷**：上传老师已有的试卷 → 校对题目、答案和分值 → 发布；答卷独立查看，不让 AI 凭空生成原试卷。
- **批改作业**：学生作业、评分要求、批改结果三个可自由切换的页面。学生可在收集期间提交，老师可先后调整评分依据。已有提交采用新标准必须由老师明确确认。

内部位置使用真实浏览器 history，刷新恢复当前位置，前进、后退不依赖滚动位置。URL 只含白名单页面、工具、步骤及不透明记录编号，不携带名称、资料或提示词。切换账号/空间清除原位置；服务端另行验证每个记录的确切所有者及成员资格。

## 动作与影响范围

- **保存**只保留私有内容，第一次保存或上传使用稳定请求编号核对原创建回执。
- **开放 / 分享**只影响当前保存项。暂停问答不会关闭同课程的作业入口。旧课程链接继续按原授权兼容。
- **执行 AI**需要明确操作并受现有电力预算约束；普通保存、课程选择、上传、删除和恢复不调用模型。
- **移入回收站**有可见单项及批量入口，事先说明学生链接和关联保存项的影响。软删除保留学生提交原件、已有成绩与账本。恢复保持关闭，由老师重新决定开放。
- **更新课程资料**不会误撤销其它保存项的学生会话。已经提交的作业和已绑定的评分依据继续保留其原快照。

本次仅提供用户自行管理记录的界面和接口，不自动清理任何生产测试数据。不改生产价格、不自动扣费。
