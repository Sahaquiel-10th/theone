# 课程教学与统一工作台外壳

2026-11-04，本轮按老师的实际教学顺序调整产品：创建课程 → 集中准备课程资料 → 使用课前、课中、课后工具。行业目录中仍是一个「课程教学」入口，归于「教育教学」；课前问答、课中游戏、课后作业依赖同一门课的材料与收件，保留在课程内，避免拆成没有共同上下文的目录卡片。

## 本轮约定

- 课程是教师组织工作的单位。历史以单任务保存的课程继续可打开，原有提交和批改记录保留。
- 学生通过老师分享的活动链接，填写姓名、班级后上传自己的作业；一份作业可以包含多份附件，也可只交附件。老师可代传。批量选择文件、移除所选文件与取消上传是不同操作，取消上传不会自动提交作业。
- 课程资料共用，支持后续查看、修改与移除引用；外部知识库保持已授权范围内按需读取，不复制整个知识库。
- 老师可以先收作业、后确认评分标准。原始提交快照保留；更换本次批改依据需要明确确认，已发布成绩不随标准变化。
- 作业的教师评分要求可直接在收件页保存，不用暂停课程或更换学生链接。该专用更新不改学生题目、作业要求或会话撤销水印，原学生能继续查看自己的已发布反馈。修改共用资料、学生题目或作业要求仍需暂停入口后操作。
- 课程级 AI 用量设置放在课程顶部；电商工具也统一为顶部默认收起的用量设置。设置上限与真正运行 AI 分开，沿用 ONE 现有价格及按实际用量结算。
- 工作台占用主内容区域，同时共用 ONE 的侧栏、小眼睛、液态玻璃表面与几何布局。切换页面不重置侧栏状态，不隐藏用于计算外壳的画布。
