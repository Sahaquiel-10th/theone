# 官方智能体灰度运行实施

本批落实 0.4.x 下一步：后台制作 → 官方认定 → 指定账号上架 → 使用者选择自己的知识 → 执行 → 私有结果与费用。不是开放市场，不改变个人分身边界。

## 发布与知识

- 认定不自动上架。超管持 Key 显式选择内测账号并发布一个已认定版本；草稿变更不影响线上版本。下架/停用立即阻止后续步骤，重新上架需明确操作。
- 官方定义只声明是否支持/要求个人知识；用户每次选择本人空间的已连接来源。连接 ID 与账号绑定摘要仅存本人任务，运行中撤销或换账号即中止，不退回全来源搜索。
- 只提供已支持的只读工具；用户执行前看到费用承担、外发地址、使用边界并确认。私人知识不会变成官方公共知识，也不给管理员或作者查看。

## 执行

- 普通用户使用独立的持 Key 路由，不开放超管试运行接口。付款人就是执行者，价格复用当前模型计费，不新增收费倍率。
- 复用现有幂等记录、私有对话存储、调度器和用量账本，增加紧凑的功能/发布版本元数据，无需新数据库表。正文只留本人私有对话和调试记录。
- 提交返回任务回执；列表分页，详情按需读取，页面刷新后可找回；重复提交不重复执行。服务器重启沿用中断标记，不自动重跑未知用量。
- 单任务 0.001–10 电力上限；同一用户空间最多一笔此类运行，有限模型轮次；每次预留计入整任务预算。
- 这批不包含 MCP、凭证接口、写入、访客收费、对外 API；仍在后续计划，不标成已完成。

## 检查

固定发布版本、下架/撤权、Key 移除、跨空间来源/结果/账本隔离、幂等与刷新恢复、费用上限、列表分页、用户目录不泄露后台配置、生产构建。真人知识质量与供应商效果由用户集中验收；开发回归不能省略。

## 本批实现与使用入口

- 管理 → 官方智能体：知识能力分“不使用 / 按需选择 / 必须选择”。知识连接仍由每位使用者运行时选择，最多五个。
- 保存并认定后，展开“上架与内测账号”，搜索、分页勾选 1–100 个有效账号，明确确认后上架已认定版本；可单独下架。停用同时撤下目录，恢复草稿或重新认定不会自动上架。
- 功能 → 官方精选：仅列为当前账号开放的功能。填写任务、选择自己的知识、确认外部工具数据去向和电力上限后提交。
- 功能 → 我的功能任务：分页查看状态、结果、工具参数与返回内容、各次模型费用。刷新/重复提交不会重跑；服务器重启把未完成任务标成中断。原文仅本人可见，超管不因角色取得别人的结果。
- 所有正式任务复用调度器、模型账本和知识连接器。单任务最多四轮，每轮最多两个工具；同一空间用户最多一笔功能任务进行中，每分钟最多 20 笔新任务。
- 草稿试运行暂只测试模型及 HTTP 工具；本人知识验收可先仅向自己的账号上架，再从功能入口进行，不开放给其他用户。不是后台替用户授权知识。
- 更新无需启动器升级、数据库迁移或重新灌装，不自动修改价格、不自动上架、不进行生产付费调用。
