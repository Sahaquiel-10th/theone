## 得到授权

- 真实接口在尚未授权时返回 HTTP 200、success=true、data.msg=authorization_pending，不能据此判定已经连接。
- 仅拿到有效 api_key 才进入已连接状态；支持 pending、slow_down、拒绝和过期响应。
- 前端等待期间继续轮询；暂时网络错误退避；终止错误和到期允许重新授权，提供取消本次连接入口。
- 已补真实响应形状的回归测试。第三方授权网页自身的失败仍需在用户出现问题的浏览器中复测，不能由上述测试推断已解决。

## 执行与调试

- macOS 安装包包含 Codex 及同目录的 code-mode-host、rg（存在时），不复制用户的登录凭证。
- 后台进程继承系统显式 HTTP/HTTPS 代理，保留已设置的代理环境变量；不承诺 PAC、认证代理和全部网络环境已适配。
- Launcher 短暂掉线会重试连接，不反复打开浏览器；服务拒绝或另一份 Key 接管时停止重试。运行中任务跨断线的结果补传/恢复尚未完成验收。
- “本轮结束”只表示 Codex 进程结束，不等于文件操作达成；验收需检查实际产物。
- 执行页可展开上下文调试，查看实际压缩指令和截至选中消息的源上下文。接口要求同一 workspace 且同一任务所有者，不向其他用户或管理员开放。
- 冒烟脚本可显式传入测试文件路径，同时校验服务端结果与文件内容；超时必须失败。
- 本机实测通过：生产 ONE 创建任务，USB Launcher 调用 Codex，目标目录写出 one-codex-smoke.txt，内容精确为 ONE_CODEX_OK；命令事件、文字回复和终态返回 ONE，执行上下文接口可读取本次指令。
- 本次验证使用已有 ChatGPT 登录的 Apple Silicon Mac，不代表未登录新设备可直接执行。23 项自动测试、TypeScript、生产构建及 macOS 深度签名校验通过。

## 后续连接边界

采用受审核的 MCP 或标准 HTTP API 连接模板；不提供任意文档自动生成并执行连接代码的入口。
协议统一不代表自动获得安全性。每个模板仍需限定目标域名、授权范围、读写权限、租户绑定和凭证存储。
Windows、新设备 Codex 登录、断线恢复、签名公证和跨设备授权保留行为均须单独验收。
