# ONE 内容优先的工作面板密度修复

基线：f8c3916，当前线上版本。用户要求解决任务列表、对话和同类模块被大按钮与多层留白挤占的问题。本轮先备份，再从当前线上代码建立隔离副本。

## 改动

- 任务层使用接近完整桌面视口，顶部标题70→48px；移除内外层重复按视口扣高，列表与对话占据余高、分别滚动。任务和功能运行记录切换保持同一外框尺寸。
- 任务卡58px，标题单行省略并保留完整提示。搜索/筛选紧凑；已读、分页、加载更早记录不再各占大行。未选任务时用多列总览，选中后保留左侧单列锚点。
- 详情标题和操作同排；44px输入框与底部输出/发送工具行，保留草稿、恢复与授权入口。正文仍14px，不靠缩正文提高密度。图文成果卡和附件改为紧凑结果行。
- 功能分类保持一行可滚动，多选列表单独滚动，完成栏固定可见；分身宽列表108px记录，窄列表132px，分享链接/更多展开仍246px。长名保留完整title。
- 知识来源搜索与筛选同排，来源卡66px，减少重复段距。历史列表已检查，行高约54px。业务接口、权限、费用和执行流程未变。
