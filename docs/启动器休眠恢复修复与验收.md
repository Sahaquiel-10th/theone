# 启动器休眠恢复修复与验收

2026-09-22，候选启动器版本 0.3.9。

## 修复

- Mac 优先验证原路径与设备 ID；原路径失效或被另一枚 Key 占用时，最多每 10 秒重新发现挂载卷。挂载、唤醒事件允许立即重新发现；卸载立即关闭连接并清除路径。
- Mac 握手限定 8 秒，失败或取消后关闭未完成连接，避免遗留握手阻塞恢复。
- Windows 唤醒检测后立即重连；重新发现盘符变化后更新凭证路径，不继续使用旧盘符。
- 服务端在拒绝同电脑重复连接前要求旧连接完成新签名；旧连接 2 秒无响应则关闭并允许新连接接管。每个业务请求仍需新鲜签名，不放宽 Key 在场要求。

## 资源

保留现有每 500 毫秒的单路径移除检测；正常连接不全盘扫描。Mac 缺席时的兜底卷发现最多每 10 秒一次，只检查固定凭证路径，不递归读取盘中文档。恢复检查不调用模型，不消耗电力。实际 CPU 与权限提示频率仍须真机观察。

## 验收状态

通过 TypeScript 检查、应用测试、生产构建，Mac Universal 与 Windows x64 编译；服务端测试覆盖活连接拒绝重复、失去响应的同版连接恢复、请求签名及租户隔离。

尚待 Mac/Windows 真机：休眠时拔盘、快速拔插、重挂载后缀/盘符变化、错误 Key 占旧路径、反复双击、在线升级后的拔出拦截及自动恢复。编译通过不等于已完成真机验收。
