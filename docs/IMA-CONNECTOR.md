# 腾讯 ima 只读连接器

## 官方依据

- [官方 Agent 接入与凭据入口](https://ima.qq.com/agent-interface)
- 页面当前发布的 [ima 官方接口包 1.1.10](https://app-dl.ima.qq.com/skills/ima-skills-1.1.10.zip)：仅阅读说明与参数，不安装或运行其中的 Skill/脚本。
- 接口是普通 HTTPS POST JSON，用 `ima-openapi-clientid`、`ima-openapi-apikey` 请求头认证；不依赖 OpenClaw，也不借用其他客户的凭据。

## 用户流程

1. 在“知识连接”打开“腾讯 ima”，前往官方页面生成本人的 Client ID 与 API Key。
2. 分别填写，或将官方复制的两行配置信息粘贴到任意字段，自动填入两项。
3. 点击“检查并连接 ima”，通过真实知识库列表和笔记本接口校验后才保存加密凭据并显示已连接。失败不覆盖已有有效连接。
4. 五个以内的知识库默认全部选择；更多时先只检索个人笔记，界面要求选择最多五个知识库。选择后显式保存。列表最多展示 100 个，超出会提示，不声称完整覆盖。
5. 后续按问题关键词实时检索；可检查连接、刷新知识库列表、更新凭据或断开。列表刷新复用服务端凭据，不要求再次复制；新增库不自动扩大检索范围。断开不删除 ima 资料、不全局撤销可能被其他应用使用的官方 API Key；用户可在官网撤销。

## 能力与边界

- 只允许六个固定端点：`search_knowledge_base`、`list_notebook`、`search_note`、`search_knowledge`、`get_media_info`、`get_doc_content`。不提供任意路径、MCP 工具、Skill 运行、上传、创建或追加接口。
- 个人笔记：标题/正文关键词候选搜索，再读取获准的纯文本正文；非作者等权限错误不以摘要冒充正文。
- 所选知识库：使用 `search_knowledge` 的 `highlight_content` 命中片段。无片段时，仅尝试读取笔记类型媒体正文。普通文件没有可读片段时不下载原文；媒体返回的 URL 和访问 headers 不透传、不请求、不进入模型。
- 这是 ONE 的“检索增强回答”资料入口，不是 ima 内部的语义召回/向量分数/知识库问答 API。当前不新增语义模型调用，也不全量同步、建立本地向量库或无限扫描所有资料。
- 同时搜索正文和标题、最多五个已选知识库；候选按本地关键词相关性选择，最多返回五条，每条 24,000 字符。整个请求有时限、固定响应字节上限和租户/全局并发上限，仍受 ONE 现有全平台上下文预算限制。

## 安全

- 所有管理操作校验当前启用用户、活动 Workspace、有效所有者 Membership；请求体中的身份、URL、路径和额外字段均不作为授权依据。
- Client ID 与 API Key 分别 AES-GCM 加密，AAD 绑定 Workspace、ima、字段用途。公开状态、错误、审计、模型上下文均不返回凭据。
- 读取绑定原始 Workspace、凭据拥有者、加密凭据与所选范围快照；断开、换凭据、修改范围或撤销拥有者权限后丢弃迟到结果，迟到验证不能重新连接。
- 官方凭据可能包含写权限；只读承诺由 ONE 审核过的适配器落实，不声称官方签发了只读 Key。
- 资料作为不可信参考，不能提升权限或启动本地执行。拒绝重定向与任意远端下载；上游错误只映射为固定安全提示，不回显原始 `msg`。
- 运维可通过 `ONE_DISABLED_CONNECTORS=ima` 停用新连接、检查、检索；断开仍可用。无需重新灌装启动器或数据库 DDL 迁移。
