# 学生学习空间 V1（2026-11-05）

已确认范围：老师发放账号；手机号仅作用户名，不做短信验证；首次登录改密；按班级授权课程；默认课程辅导；作业、测验、课堂游戏、个人剧本与提交分开。

## 使用流程

老师从课程工作台进入「班级与学生」，创建班级、分配课程，上传 CSV / XLSX / XLS 名单（姓名、手机号，学号可选）。核对预览后确认导入，下载账号发放表，再自行分发。每批最多 200 人。已存在的手机号只新增选课关系，使用学生原密码。发放表的初始密码导出有效期为 24 小时；老师只能重发自己发放且尚未激活、未关联其他老师的初始账号。

学生入口为 `/learn`；教师可复制带教师标识的登录链接。学生使用手机号和初始密码登录，设置自己的密码并保存恢复码，以后可换设备登录。课程辅导、作业和测验使用同一个稳定学生身份；原有匿名登记不按姓名或学号自动合并。已配置账号班级的课程不再允许匿名登记。教师提供的活动链接会引导学生登录并定位相应课程/活动。

班级可以移入回收站、恢复；恢复后保持入口停用，由老师在班级设置中启用。移出学生、停用/删除班级、移除课程分配、撤销教师空间权限都会使旧课程令牌失效。

## 剧本与游戏

「我的剧本」支持文字编辑及 TXT / Markdown / JSON 文件导入，个人保存、下载、回收站恢复；主动「交给老师」时确认目标课程，老师收到不可变的指定版本副本，后续编辑不会覆盖原提交。普通上传作业继续支持原有批量附件流程。

课堂游戏复用已上线游戏模块；老师在班级设置中明确布置自己审核通过的作品，学生只可进入这些作品。其他学生的私人剧本和老师未布置的预览不进入课程游戏列表。个人剧本 AI 创作/试玩费用尚未确认，本版本不开放相应付费调用；手动保存和提交不调用 AI。现有课程辅导、课堂游戏沿用原有教师课程授权、余额和学生入口保护上限，没有调整价格或自动解除上限。

## 隔离与凭据

学生不是 ONE 用户/空间成员，不获得 ONE Key 或教师接口权限。账户哈希、登录哈希、个人草稿均放在现有私有 `User.teaching` JSON 中，不通过 `publicUser` 返回。老师接口仅返回本用户、本空间的班级、名单、发放记录和已提交副本。跨老师复用同一手机号不透露其他班级/原密码，也不重置原密码。

学生使用独立 HttpOnly / SameSite=Strict Cookie，生产环境 Secure，修改操作校验自定义请求头和跨站来源。每次活动令牌绑定具体登录版本，退出/改密/恢复码找回会撤销相应旧令牌；消费预留在原子写入前再次检查权限。初始密码仅以带账号/空间上下文的 AES-GCM 密文保存，密码使用异步 scrypt；不记录凭据明文日志，不给老师查看学生自定密码。恢复码随机生成、单次轮换，仅存哈希。

私有数据使用既有 JSON/SQL `record_json` 存储路径，无新增迁移或知识副本。课程永久删除预览包含已交给老师的剧本，个人草稿独立保留；财务账本沿用原保留规则。

## 验证边界

自动检查覆盖账号批量导入与回执幂等、跨用户/空间隔离、首次改密、跨设备同一提交、退出/改密/移出班级撤销、私有剧本与不可变提交、课堂作品分配、消费预留前撤权、班级恢复关闭、真实 JSON Store 重启、XLSX 文件导入。完整测试、TypeScript 和生产构建另见本次发布检查。

本地浏览器使用明确隔离的合成账号/模型验证桌面流程。没有创建生产学生、重置真实密码或使用真实模型付费。用户要求停止手机端核对，本次不宣称完成手机浏览器验收。可在本地行业 QA 启动时设置 `ONE_INDUSTRY_QA_STUDENTS=1` 生成专用合成场景；生产入口不导入种子脚本。
