# 教师剧本上传提交修复

问题：教师上传的附件已保存，但旧的知识授权失败和本次用量确认提示同时展示，缺少可执行的恢复路径。教师确认用量后，还需再次点击提交；旧失败记录容易被误认为本次仍在执行。

修复：
- 开始付费调用前，以当前老师、空间、课程和条目检查课程资料授权；此检查不检索正文、不创建 AI 操作、不预留电力。
- 授权需要重选时，在原稿所在页面重新选择、明确确认知识范围并保存。保留附件和正文，不自动换账号、扩大范围或重新授权。
- 用量弹窗显示“确认并继续提交”。确认后继续同一请求编号、同一组附件；取消/关闭页面则不执行。
- 旧失败明确标为“上次”；修复授权后清除过时的当前错误。上传进度、已上传、待确认和审核中分别展示。
- 未确认结果只查询旧回执；已完成的原稿重新执行使用明确的“重新审核”文案。
- 服务端在创建新操作前再次检查授权，并为执行途中权限变化保留结构化错误码。既有请求回执仍按原编号查询，不自动重发。

验证：新增预算确认等待/取消/重复等待/原始载荷测试，知识授权预检查的只读性、跨空间和失败零费用测试。桌面真实组件配合隔离合成连接与模型，验证附件上传、原页面重选资料、取消确认、确认后单次审核及生成试玩入口。一个审核操作正常包含审核和导演编译两次合成模型调用；未产生真实模型费用。原账号只读核对确认原“渡口无归人”附件仍保留。
