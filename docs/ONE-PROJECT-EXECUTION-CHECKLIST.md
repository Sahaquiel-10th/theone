> 状态：MVP 生产基线已上线，进入真实线上链路验收

> 唯一首版目标：**ONE Key 登录 + 得到大脑授权 + 实时知识召回 + AI 上下文问答。**

## 1. 首版结论

第一版不建设 ONE 自有知识库，不同步保存外部笔记，也不实现活记忆理念。得到大脑只是首个 Knowledge Connector；后续 Notion、印象笔记和 ONE 自有库使用同一业务边界接入。

用户前提：

- 已经注册得到大脑并开通会员；
- 没有账号时由 ONE 运营人工协助；
- 第一次必须在官方页面完成授权；
- 后续由 ONE 后台实时调用，不再要求用户操作第三方平台。

## 2. 标准验收旅程

1. 运营批量灌装未激活 ONE Key，不提前绑定用户。
2. 用户插 Key、双击 Launcher，并以手机号验证码/微信完成首次认领。
3. ONE 创建或匹配用户与 Workspace，绑定 Key，浏览器自动登录。
4. ONE 提示首次连接得到大脑，用户完成一次官方 OAuth 授权。
5. 用户提出一个只有其得到笔记才能回答的问题。
6. ONE 全局召回相关笔记，交给 AI 回答并展示来源。
7. 严格模式拔出 Key 后页面锁定，重新插入后恢复；受信任设备普通功能可长期使用。
8. 一个用户可以绑定并命名多枚 Key；挂失设备进入归档且永久失效。
9. 断开得到、授权过期或 Key 被挂失后，对应能力立即失效。
10. 另一个 Workspace 无法获取任何相关数据。

## 6. 快速上线红线

- 不用共享得到账号模拟多租户；
- 不在浏览器、本地日志或 U 盘明文保存 Provider API Key；
- 普通 U 盘不得宣传为安全芯片级不可复制；
- 不让 Provider 失败跨 Workspace 兜底；
- 不在首版顺手建设同步、向量库、Memory、Notion 或复杂编辑器；
- 新身份和知识路径必须有跨 Workspace 测试；
- 真实用户上线前必须完成代码签名/公证和授权撤销测试。
