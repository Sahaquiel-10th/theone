# ONE 0.4.x 核心调度与分身开放实施方案

确认日期：2026-09-23。本文是实施和后续交接基线，不代表功能已上线。

## 一、产品决策

- 核心调度 Agent 是后续所有工具的统一执行入口；工作台、分享网页、外部 API 共用执行系统，不各建一套。
- 调度模型在有权使用的工具集合中选择行动；服务端独立校验权限、预算、参数、执行结果。不是固定每次调用拆解、搜索、总结三个模型。
- 网页分身优先，API 同属 0.4.x 范围。用户发布前勾选知识来源；公开分身只回答问题，不开放私人聊天、本机文件和其他执行能力（2026-09-25 用户确认）。
- 个人工作台保持 Key 在场要求；公开服务在明确发布后可在主人拔 Key 时运行。发布、变更权限、额度、收费仍要求本人 Key 在场。
- 所有在用 AI 任务进入配置中心，不仅核心调度。包括聊天、附件整理、对话转本地执行指令、本地执行、图片生成；未来任务必须登记。
- 列表、搜索、分页、按需展开是验收项，不以美化替代可用性。
- 暂不实现每日主动巡视、全量同步知识库、自动提现。本轮不改变启动器版本；网站版本与启动器独立。

## 二、分身与付费分期

第一批开放发布者买单的网页分享和 API；先不做访客充值收费，避免支付结算拖住调度闭环。执行账本从一开始记录入口、发布者、访客会话、任务、模型调用和实际费用。

后续收费复用同一执行系统，但另需支付和收益子账本，不是简单增加倍率字段即可上线。0% 表示发布者承担；100% 转收 ONE 实际服务费用；120% 表示成本加成 20%，不是净利率 20%。允许补贴倍率时须明确承担者。

访客充值款、未消费余额、已消费收入、ONE 服务费、退款、赠送电力必须分开。不能把访客充值直接视为发布者已赚取收入，也不能将赠送电力变成可提现收益。暂不提现；未来结算条件另行确认。执行开始固定价格版本与倍率，失败、重试仍记录真实产生的模型费用，不宣称失败必然免费。

## 三、授权与知识范围

- 执行身份由服务端解析：workspaceId、主体、入口、分身发布版本、授权、付款方；不信任浏览器自报 workspaceId。
- 工具权限取入口策略、发布权限、实际连接授权、任务配置的交集。提示词不能扩大权限。
- 公开入口不允许本机工具，不能复用私人聊天路由跳过 Key 校验。
- 公开网页及后续同类分身 API 的能力上限固定为：读取发布时明确授权的知识、生成文字回答。禁止联网搜索、附件上传/解析、图片生成、本地执行、写文件、保存笔记、发送消息、发布内容及调用其他 Agent。不是“默认关闭、管理员能打开”；本轮后台工具配置和分身提示词都不能扩大这一上限。
- 知识读取是回答的内部步骤，不在分享页面暴露工作台工具菜单。没有勾选知识来源时仅做文字问答，不自动读取发布者全部知识。
- 连接器若只能账号级搜索，发布页必须明确是分享整个授权账号范围；不伪装成单文档授权。不具备可靠范围控制的细粒度分享不开放。
- 分享链接不等于保密措施；支持关闭、到期、额度、频率限制；受限分享需访问校验。
- 发布版本固定知识范围和行为配置；改权限须重新发布。撤销连接和关闭发布对后续步骤立即生效，不能用旧快照绕过撤销。
- 访客会话隔离；超管及发布者默认仅看运营元数据，不查看他人对话。完整调试原文只看本人任务。

## 四、执行系统

任务具有稳定编号、入口、归属、付款方、配置版本、状态、预算和步骤；步骤关联模型调用、工具调用及产物。状态包括排队、执行、待确认、成功、部分完成、失败、取消。

工具目录描述参数结构、读写风险、需要的连接、允许入口和验证方式。对外发送、删除、发布等高风险操作需绑定具体参数的确认；重试先核实是否已执行。外部网页、工具和知识内容是不可信资料，不能授权新行为。

支持幂等键、有限重试、超时、取消、进程重启恢复和预算并发预留。网络超时可能意味着结果未知，不能直接重试有副作用操作。成功依据真实工具结果或可验证产物，不依据模型自称完成。

## 五、AI 任务配置中心

现有调用盘点：

| 任务 | 当前实现位置 | 目标 |
| --- | --- | --- |
| 聊天回答 | server/index.ts 聊天路由 | 模型策略、提示词、能力配置 |
| 附件分段整理 | server/index.ts attachment_summary | 独立模型、整理提示词、处理预算 |
| 对话转执行指令 | server/index.ts executions/from-message + executionService.ts | 独立模型、编译提示词，不能扩大用户意图 |
| 本地 Agent | server/localAgentService.ts | 模型、提示词、允许工具和步骤上限 |
| 图片生成 | server/modelGateway.ts callImageModel | 图片模型及适用提示词，不强行套聊天工具 |
| 核心调度 | 新增 | 模型、提示词、工具目录、执行预算 |

供应商连接、模型定价、任务配置分离。价格继续使用现有权威价格源，不在每个任务重复填写。任务页面显示所选模型的当前价格与实际测试消耗。

配置支持草稿、测试、发布、版本记录、回滚。运行固定发布版本；安全约束由代码强制执行。明确平台规则、模型提示词、任务提示词、分身指令的拼装顺序，并在本人调试中展示实际输入。没有工具的任务不展示假工具选择器。

后台默认每页 20 项，支持搜索与筛选，详情按需加载；任务、模型请求、日志不能一次全量展开。提示词长文本折叠；编辑器独立面板，避免页面无限增长和遮挡按钮。

## 六、实施里程碑与验收

1. M1：现有 AI 调用清单、统一任务定义、配置存储/接口/后台；先保持旧行为默认值，逐一迁移调用点。任何登记却未接线的能力明确标注不可用。
2. M2：任务/步骤持久化、权限解析、预算和账单关联；核心调度在工作台完成真实检索与回答，并完成一个已支持且验证过的工具流程。
3. M3：网页分身发布、知识范围、访客隔离、发布者买单、限额、撤销；不开放未完成计费隔离的公共入口。
4. M4：外部任务 API、独立密钥哈希存储/轮换/撤销、幂等提交、异步状态与结果查询；复用 M2/M3。
5. M5：真实用例回归与公开服务安全验收；访客收费在此之后单独实施，不阻塞前四阶段。

每阶段检查类型、相关测试、跨租户隔离、生产构建和 diff。通过验证的独立增量按仓库授权提交推送，检查部署健康；未完成入口保持关闭。数据库迁移追加，不修改已共享迁移，不删除用户记录，不自动改生产价格。

发布验收必须覆盖：Key 在场与拔插；公开入口无本机权限；访客隔离；来源越权拒绝；撤销及时生效；并发额度；重复提交不重复写入/记账；模型超时/工具结果未知；真实产物；可查实际模型/配置版本/费用；管理员不能读取他人原文。

- 开始：M1 任务目录与定义的代码化。
- 未完成：配置中心接线、统一调度运行器、公开分身授权、API、访客收费。不能把目录或单测通过称为 Agent 已交付。

### M1 第一批配置接线（2026-09-23）

- 后台新增 AI 任务入口；搜索、列表、详情弹窗、模型搜索分页、历史折叠与分页。
- 五个现有调用点接入：聊天、附件摘要、执行指令编译、本地执行、图片生成。核心调度显示开发中，不开放配置发布。
- 配置保存在现有系统设置中，不新增数据库；只有经过 Key 校验的超管能读写。全局配置不保存用户聊天内容。
- 支持草稿、显式发布、并发修订检查、历史回滚为新版本。默认无覆盖，保持旧行为；不自动调整价格或发布任何生产配置。
- 模型调用用量记录增加 aiTaskVersion；实际模型仍通过现有账本记录。价格继续在原有定价入口管理。
- 本批提示词为补充指令，不能替换原有安全约束；尚未实现全部内置模板编辑、配置中心测试运行、逐步骤任务调试和预算控制，不能视为 M1 全部完成。
- 本地工具勾选和步数限制已接执行端，不仅修改模型可见工具。公开网页/API 尚未开放。

### M1/M2 第二批：预制指令与可编辑工具说明

- 任务详情显示预制提示词，支持编辑、恢复预制配置；旧版补充提示词继续兼容，编辑发布时转为完整任务指令。平台权限、安全验证仍独立执行。
- 工具逐项折叠，管理员可以编辑“何时调用”，发布后实际进入 function calling 的 description。名称和参数结构由代码固定，不能填写任意 URL 或任意新工具。
- 核心调度首版仅用于无附件的文本聊天，默认关闭；管理员勾选启用并发布才切换。关闭后回到原有流程。图片、附件不改路由。
- 提供知识库搜索和联网搜索两个只读工具；联网仍需用户打开联网开关。知识检索绑定请求所属 workspace，模型参数不能指定 workspace。
- 最多四轮模型调用，每轮最多两个工具调用；最后一轮收束回答；相同查询在单次任务复用。每个步骤重新校验 Key 和对话归属，每次模型调用按原账本结算。
- 本人上下文调试记录实际调度消息和步骤；独立分页任务调试视图、整任务费用预算、带费用测试运行、耐久调度恢复尚未完成，不能视为公开 API 所需执行底座已完成。
- 真实供应商的工具选择质量仍需使用管理员自己的问题验收。自动化测试验证机制，不代表已验证真实召回效果。

### 调度追踪与工具目录补充

- 上下文调试记录与调度追踪合并到同一条本人任务记录：原始上下文继续按段展示；若发生调度，额外按步骤折叠展示工具、查询、返回摘要、状态、是否复用和耗时。
- 追踪结果有长度上限，保留调试价值但不把无限大的知识原文或响应写入页面。服务端仍按 workspace/user 隔离；管理员不能借此查看其他用户聊天。
- 工具分为“已注册工具”和“任务允许工具”。后台可以动态启用/禁用已注册工具、编辑给 AI 看的调用说明；工具参数 schema、真实执行器、Key/连接器/本机权限由代码固定。
- 新增全新工具必须先实现服务端执行器并加入注册目录，再开放到对应任务；后台不能仅填写函数名就凭空生成工具。

### M3 前置边界：公开分身只做问答（2026-09-25）

- 用户确认公开分身不调度本地工具或其他功能。执行入口改为显式参数；现有工作台由服务端固定传入 workspace，不能由浏览器传入。
- 公开网页及同类公开 API 的工具上限固定为 knowledge_search；未知入口拒绝执行。全局配置、授权列表、localOnly 标志都不能扩大这一上限。
- 调度器启动前拒绝含禁用工具的配置，不产生模型费用；模型伪造工具调用也不会执行。
- 这是能力边界防线，不是公开授权系统。知识处理器仍必须绑定发布版本内的准确授权来源，不得直接复用工作台全来源检索。
- 本次没有开放公开路由、生成分享链接或自动发布任何账号的知识。M3 的发布记录、来源授权、访客隔离、任务预算/并发限制、账本和页面尚待实现；公共入口必须等待这些验收通过再开放。
